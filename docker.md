# Docker run, ps, logs, stop
'docker run'Создать и запустить контейнер из образа
Флаг -d	Запуск в фоне (detached), терминал остается свободным
Флаг -p 8080:80	Проброс порта: порт хоста ведет на порт внутри контейнера
docker ps	Показать работающие контейнеры; с -a еще и остановленные
docker logs	Показать логи контейнера; с -f следить в реальном времени
docker exec -it	Выполнить команду внутри работающего контейнера, например зайти в его оболочку
docker stop / docker rm	Остановить контейнер; удалить остановленный
Docker Hub	Публичный реестр готовых образов, откуда Docker их скачивает

docker run -d -p 8080:80 nginx   запустить контейнер в фоне с пробросом порта
docker ps                        показать работающие контейнеры
docker ps -a                     показать все, включая остановленные
docker logs <id>                 посмотреть логи
docker logs -f <id>              следить за логами в реальном времени
docker exec -it <id> bash        зайти внутрь контейнера
docker stop <id>                 остановить контейнер
docker rm <id>                   удалить остановленный контейнер

Словарик
Термин	Что означает
Dockerfile	Текстовый файл-инструкция, по которой Docker собирает образ
Слой	Результат одной инструкции Dockerfile; образ складывается из слоев
FROM	Базовый образ, с которого начинается сборка
RUN	Команда, выполняемая во время сборки образа
CMD	Команда, запускаемая при старте контейнера
docker build -t	Собрать образ из Dockerfile и дать ему имя (tag)
Кеш слоев	Неизменившиеся слои Docker берет из кеша, ускоряя пересборку

# базовый образ
FROM python:3.12
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 8080
CMD ["python", "app.py"]

docker compose up -d        поднять всю связку в фоне
docker compose down         погасить и убрать контейнеры и сеть
docker compose ps           показать сервисы этого проекта
docker compose logs -f      смотреть логи всех сервисов сразу
docker compose logs -f app  смотреть логи одного сервиса
