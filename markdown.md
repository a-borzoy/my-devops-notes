# Шпаргалка по Cloud Computing для собеседований

## 1. Базовые понятия и бизнес-велью

* **Cloud Computing (Облачные вычисления)** — предоставление вычислительных ресурсов (серверов, хранилищ, БД, сетей, ПО) через интернет по требованию с оплатой по факту использования.
* **CapEx vs OpEx**:
  * *CapEx (Capital Expenditures)* — капитальные затраты. Покупка своего железа, постройка дата-центра.
  * *OpEx (Operational Expenditures)* — операционные затраты. Оплата облака как коммуналки (только за то, что израсходовано). Облака переводят IT-затраты из CapEx в OpEx.
* **Масштабируемость (Scalability)** — способность системы справляться с увеличением нагрузки (добавлением ресурсов).
  * *Вертикальная (Scale Up)* — увеличение мощности одного сервера (добавили CPU/RAM). Есть физический лимит.
  * *Горизонтальная (Scale Out)* — добавление новых серверов в кластер. Лимита практически нет.
* **Эластичность (Elasticity)** — способность облака автоматически выделять и изымать ресурсы в зависимости от текущей нагрузки (автоскейлинг).
* **Отказоустойчивость (Fault Tolerance)** — способность системы продолжать работу при выходе из строя отдельных компонентов (за счет репликации и избыточности).

## 2. Модели обслуживания (XaaS)

Разделение зон ответственности между клиентом и облачным провайдером:

| Уровень / Компонент | IaaS (Infrastructure) | PaaS (Platform) | SaaS (Software) |
| :--- | :---: | :---: | :---: |
| **Приложения и Данные** | Клиент 👤 | Клиент 👤 | Провайдер ☁️ |
| **Среда исполнения (Runtime) / БД**| Клиент 👤 | Провайдер ☁️ | Провайдер ☁️ |
| **Операционная система (ОС)** | Клиент 👤 | Провайдер ☁️ | Провайдер ☁️ |
| **Виртуализация и Сеть** | Провайдер ☁️ | Провайдер ☁️ | Провайдер ☁️ |
| **Физическое железо / ДЦ** | Провайдер ☁️ | Провайдер ☁️ | Провайдер ☁️ |

* **IaaS (Infrastructure as a Service)**: Провайдер дает "сырые" ресурсы (виртуальные машины, диски). *Примеры: AWS EC2, Yandex Compute Cloud.*
* **PaaS (Platform as a Service)**: Провайдер дает готовую платформу (рантайм, управляемые БД). Клиент пишет только код. *Примеры: Heroku, Yandex Managed PostgreSQL.*
* **SaaS (Software as a Service)**: Готовое ПО по подписке. *Примеры: Google Drive, Jira.*

## 3. Модели развертывания

* **Public Cloud (Публичное)**: Инфраструктура доступна всем, ресурсы делятся между разными клиентами (*multitenancy*), но изолированы логически (AWS, Azure, Yandex Cloud).
* **Private Cloud (Частное)**: Инфраструктура используется строго одной организацией. Разворачивается на собственном железе или изолированно у провайдера (OpenStack, VMware).
* **Hybrid Cloud (Гибридное)**: Комбинация Public и Private. Например: критичные и персональные данные хранятся локально в Private, а веб-фронтенд под высокую нагрузку развернут в Public.

## 4. Ценообразование и FinOps (Сколько стоит облако)

Облака работают по модели **Pay-as-you-go** (оплата по мере потребления).

### За что именно списываются деньги?
1. **Compute (Вычисления)**: Время работы vCPU и объем RAM. Тарифицируется посекундно или поминутно, пока ВМ запущена.
2. **Storage (Хранилище)**:
   * *Block Storage (Диски)* — плата за зарезервированный объем (ГБ/мес) + за скорость операций (IOPS).
   * *Object Storage (S3)* — плата за фактический объем данных + за количество запросов (PUT/GET). Очень дешевое для архивов и медиа.
3. **Network (Сеть)**:
   * *Входящий трафик* — обычно бесплатный.
   * *Исходящий трафик (в интернет)* — всегда платный и дорогой.
   * *Внутриоблачный трафик* — между разными дата-центрами (зонами доступности) одного провайдера часто тарифицируется.

### Как оптимизировать затраты (FinOps-практики)?
* **Spot / Preemptible VMs (Прерыmapping / Спотовые машины)**: Виртуальные машины со скидкой до 80%, которые провайдер может принудительно погасить в любой момент (с предупреждением за пару минут). Идеально для stateless-сервисов, тестов и воркеров очередей.
* **Reserved Instances / Commitments (Резервирование)**: Скидка до 50-70% за обязательство использовать конкретные мощности в течение 1–3 лет.
* **Autoscaling**: Автоматическое тушение ненужных серверов ночью или в периоды затишья.
