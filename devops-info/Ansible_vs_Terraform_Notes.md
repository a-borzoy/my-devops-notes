# 📝 Шпаргалка: Ansible vs Terraform для VS Code

## 🏢 1. Концепция IaC (Инфраструктура как код)
**IaC (Infrastructure as Code)** — это подход к управлению и настройке инфраструктуры через конфигурационные файлы, а не вручную.

* **Декларативный подход (Terraform):** Вы описываете *конечный результат* («Мне нужно 3 сервера и база данных»), а утилита сама думает, как это сделать.
* **Императивный подход (Ansible):** Вы описываете *пошаговые действия* («Установи пакет, скопируй файл, перезапусти сервис»).

---

## 🏗️ 2. Сравнение инструментов

| Критерий | 🛠️ Terraform | 📦 Ansible |
| :--- | :--- | :--- |
| **Основная роль** | Оркестрация (Создание инфраструктуры) | Конфигурация (Настройка серверов) |
| **Тип** | Декларативный | Преимущественно императивный / Гибридный |
| **Архитектура** | Без агентов (использует API провайдеров) | Без агентов (подключение по SSH / WinRM) |
| **Состояние** | Хранит состояние (файл `terraform.tfstate`) | Не хранит состояние (проверяет статус на ходу) |
| **Язык** | HCL (HashiCorp Configuration Language) | YAML |

## 🚀 3. Шпаргалка по командам

### Terraform (Создание ресурсов)
```bash
# Инициализация рабочего каталога (загрузка провайдеров)
terraform init

# Просмотр изменений перед их применением (планирование)
terraform plan

# Применение изменений и создание инфраструктуры
terraform apply

# Удаление всей созданной инфраструктуры
terraform destroy
```

### Ansible (Настройка серверов)
```bash
# Проверка связи со всеми хостами из inventory-файла
ansible all -m ping -i inventory.ini

# Запуск сценария (плейбука) на выполнение
ansible-playbook site.yml -i inventory.ini

# Шифрование секретных данных (паролей, ключей)
ansible-vault encrypt secrets.yml
```

## ⚖️ 4. Главное правило выбора: Ansible или Terraform?
* Используйте **Terraform**, чтобы **создать** виртуальные машины, сети, балансировщики в облаке.
* Используйте **Ansible**, чтобы **настроить** операционную систему внутри этих машин, установить Docker, Nginx или развернуть приложение.

💡 *Лучшая практика (Best Practice):* Использовать их в связке. **Terraform** разворачивает сеть и серверы, а затем передает их IP-адреса в **Ansible** для финальной настройки.
