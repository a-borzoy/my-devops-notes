# Коспекты по DevOps
# Git

## 1. Как перенести конкретный коммит из одной ветки в другую?
Для выборочного переноса коммита используется команда `git cherry-pick`.
- Сначала смотрим хэш коммита в исходной ветке: `git log --oneline`
- Переключаемся в целевую ветку: `git checkout main`
- Забираем коммит: `git cherry-pick <хэш_коммита>`

## 2. Что такое мердж-конфликт и каковы его причины?
**Мердж-конфликт** — ситуация, когда Git не может автоматически объединить ветки и требует вмешательства человека.
- **Причина:** в двух разных ветках была изменена одна и та же строка в одном и том же файле. При слиянии (`git merge`) Git не знает, какую версию сохранить, и останавливает процесс для ручного выбора.

## 3. Как под капотом работает команда `git pull`?
Команда `git pull` — это совмещение двух других команд:
1. `git fetch` — скачивает новые коммиты с удаленного репозитория (GitHub) в локальный кэш (`origin/main`), не меняя рабочие файлы.
2. `git merge` — автоматически сливает скачанные изменения в вашу текущую локальную ветку.
