# Конспект: Пакетные менеджеры в Linux 📦

**Пакетный менеджер** — это встроенная утилита операционной системы, которая автоматизирует установку, обновление, настройку и удаление программного обеспечения (пакетов). 

---

## 🛠 1. Главное понятие: Зависимости (Dependencies)

Большинство программ в Linux состоят из множества мелких библиотек. Если программе **А** для работы нужна библиотека **Б**, то библиотека **Б** называется **зависимостью**.

> **Главная задача пакетного менеджера** — автоматически найти, скачать и установить все необходимые зависимости вместе с основной программой.

---

## 📂 2. Основные семейства и форматы пакетов

| Семейство дистрибутивов | Формат пакетов | Низкоуровневый ПМ | Высокоуровневый ПМ |
| :--- | :--- | :--- | :--- |
| **Debian / Ubuntu / Mint** | `.deb` | `dpkg` | **`apt`** (или `apt-get`) |
| **Red Hat / CentOS / Fedora** | `.rpm` | `rpm` | **`dnf`** (ранее `yum`) |
| **Arch Linux / Manjaro** | `.pkg.tar.zst` | — | **`pacman`** |

* **Низкий уровень (`dpkg`, `rpm`)** — работают только с локальным файлом на диске. Не умеют сами скачивать зависимости из интернета.
* **Высокий уровень (`apt`, `dnf`)** — сами обращаются в сеть, ищут зависимости и скачивают всё автоматически.

---

## 🌐 3. Что такое репозитории?

**Репозиторий** — это удаленное хранилище (сервер в интернете), где разработчики дистрибутива хранят проверенные и скомпилированные пакеты программ. Пакетный менеджер обращается именно к ним.

---

## 💻 4. Основные команды (на примере APT)

Все команды управления пакетами требуют прав администратора, поэтому выполняются через **`sudo`**.

### Обновление системы
```bash
sudo apt update
# Обновляет локальный индекс (базу данных) доступных пакетов.
# Не обновляет сами программы! Запускать ПЕРЕД установкой софта.

sudo apt upgrade
# Обновляет все установленные в системе программы до актуальных версий.
```

### Управление программами
```bash
sudo apt install <имя_пакета>
# Скачивает и устанавливает программу (Пример: sudo apt install htop)

apt search <запрос>
# Ищет программу в репозитории по ключевому слову (sudo не нужен)
```

### Удаление программ
```bash
sudo apt remove <имя_пакета>
# Удаляет программу, но ОСТАВЛЯЕТ её конфигурационные файлы.

sudo apt purge <имя_пакета>
# ПОЛНОСТЬЮ удаляет программу вместе со всеми настройками.
```

---

## 🚀 5. Универсальные форматы (Самодостаточные)

Содержат программу и *все* её зависимости в одном флаконе. Работают на любом дистрибутиве:
* **Snap** (команда `snap`) — популярен в Ubuntu.
* **Flatpak** (команда `flatpak`) — часто используется для графических приложений.
