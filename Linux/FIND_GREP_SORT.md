# 📝 Краткий конспект: Базовые утилиты Linux

## 1. Создание файлов и папок
* `mkdir имя_папки` — создает новую директорию (папку).
* `touch имя_файла.txt` — создает пустой файл.
* `echo "текст" > файл.txt` — создает файл и сразу записывает в него строку (перезаписывая файл).
* `echo "текст" >> файл.txt` — дописывает строку в самый конец уже существующего файла.

## 2. Команда `find` — поиск файлов
Используется для поиска файлов и папок по дереву каталогов.
* `find . -name "server.properties"` — найти файл с точным именем в текущей папке (`.`) и всех её подпапках.
* `find /home -name "*.sql"` — найти все файлы с расширением `.sql` в каталоге `/home`.
* `find . -type d -name "config"` — искать только папки (`-type d`) с именем `config`.

## 3. Команда `grep` — поиск текста внутри файлов
Ищет конкретные строки или слова внутри текстовых файлов.
* `grep "RateXp" rates.properties` — найти и показать все строки, где упоминается переменная `RateXp` в указанном конфиге.
* `grep -i "password" server.properties` — искать слово без учета регистра (`-i`), найдет и *Password*, и *PASSWORD*.
* `grep -r "accounts" sql/` — рекурсивный поиск (`-r`) слова во всех файлах внутри папки `sql/`.

## 4. Объединение команд / Конвейер (Pipes)
В Linux вывод одной команды можно передать на вход другой с помощью символа вертикальной черты **`|` (pipe / пайп)**.
* `find sql/ -name "*.sql" | grep "login"` — сначала ищет все sql-файлы, а затем фильтрует результат, оставляя только те, в названии которых есть слово "login".
* `cat server.properties | grep "port"` — выводит содержимое файла на экран и тут же фильтрует его, показывая только строки с портами.

## 5. Сортировка данных (Команда `sort`)
* `sort файл.txt` — выводит строки файла, отсортированные по алфавиту.
* `sort -r файл.txt` — сортировка в обратном (реверсивном) порядке от Я до А.
* `sort -n файл.txt` — **сортировка по числовому значению** (сортирует строки как числа: 2, 10, 20. Без флага `-n` система отсортирует их по алфавиту, и число 10 пойдет сразу после 1, а не после 9).
* `find sql/ -name "*.sql" | sort` — найти все sql-файлы и выстроить их список строго по алфавиту.
