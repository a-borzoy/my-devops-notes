# Базовые команды Linux (Файловая система)

## 1. Работа с папками (Директориями)
- `pwd` — показать текущий путь (где я сейчас нахожусь).
- `mkdir my_folder` — создать новую папку с именем "my_folder".
- `mkdir -p p1/p2/p3` — создать цепочку вложенных папок (флаг `-p` создаст недостающие папки автоматически).
- `cd my_folder` — перейти в папку.
- `cd ..` — подняться на один уровень вверх (в родительскую папку).

## 2. Просмотр содержимого
- `ls` — показать список файлов в текущей папке.
- `ls -la` — показать ВСЕ файлы (включая скрытые, вроде `.git`), их размер, права доступа и владельца (очень частая DevOps команда).

## 3. Работа с файлами
- `touch file.txt` — создать пустой файл.
- `cp file.txt new_file.txt` — скопировать файл.
- `mv file.txt /path/to/folder/` — переместить файл в другую папку (или переименовать его, если указать новое имя).
- `rm file.txt` — удалить файл.
- `rm -rf my_folder` — удалить папку со всем её содержимым без предупреждений (флаг `-r` для рекурсивного удаления, `-f` — принудительно). 
- `nano` - Редактирование файлов в консольном текстовом редакторе.

## 🔒 2. Права доступа и суперпользователь

*   **`sudo <команда>`** — Выполнение команды с правами администратора (суперпользователя).
    *   *Пример:* `sudo apt update` (потребуется ввод пароля).
*   **`chown <владелец> <файл>`** — Изменение автора (владельца) файла или папки.
    *   *Пример:* `sudo chown root file.txt`
*   **`chmod <права> <файл>`** — Изменение прав доступа.
    *   *Пример:* `chmod +x script.sh` (сделать скрипт исполняемым).
    *   *Пример:* `chmod 755 folder` (полные права владельцу, чтение и выполнение остальным).
